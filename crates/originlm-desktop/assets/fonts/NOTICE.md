The variable build is used instead of the asset pack's single SemiBold static
face so one file covers the regular, medium and semibold weights the interface
asks for. Upstream is the Red Hat font project
(<https://github.com/RedHatOfficial/RedHatFont>); the asset pack's
`PROVENANCE.md` records its own static-font manifest.
