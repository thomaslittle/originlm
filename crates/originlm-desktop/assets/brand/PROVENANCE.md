# OriginLM logo provenance

The current production artwork comes from the user-supplied replacement `OriginLM-Asset-Kit(1).zip`, received October 28, 2026 (UTC). Its approved reference is identified in the kit as `image(20261028-233656).png`. This single offset-O design supersedes the earlier Matched Cuts artwork; none of that earlier geometry is used in the current logo SVGs, icons or social card.

Archive SHA-256: `96d91bdf6bfe92e5de7996745795ac9be3366abbb8f769c1c40dc6c9dfc52c55`.

The supplied mark has an amber outer contour and an offset transparent counter. Horizontal lettering is supplied as vector outlines. Production assets are copied from the kit without redrawing, replacing lettering or running its build script. `brand/logo-assets.json` records each installed source asset and byte hash; `brand/logo-geometry.json` preserves the supplied geometry.

Logo colors are amber `#EBA31A`, ink `#111820` and white. Existing graphite `#231F20`, Red Hat Display typography and provider glyphs remain independent UI assets. The bundled font licences apply to font software, not product marks. No independent trademark-clearance claim is made. The project's software licence does not grant rights to third-party provider marks.
