# Bundled font

`RedHatDisplay-Variable.ttf` is the Red Hat Display variable build from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/redhatdisplay),
fetched 2026-10-27. Upstream is the
[Red Hat font project](https://github.com/RedHatOfficial/RedHatFont).
Licensed under the SIL Open Font License 1.1; see `OFL.txt`.

One variable file covers the regular, medium and semibold weights the interface
uses, so the shell does not ship a static face per weight.
