# OriginLM production artwork

The user-supplied single offset-O replacement is used directly. `originlm-horizontal-light.svg` is the amber/ink lockup for light surfaces; `originlm-horizontal-dark.svg` is the amber/white lockup for dark surfaces. Standalone marks retain their supplied transparent counters and aspect ratio. The demo app tile is the supplied native rounded icon.

See [provenance](../../../../../brand/PROVENANCE.md) and the existing font/provider notices. Favicons and install icons in `public/` come from the same replacement kit. Logo ink is distinct from the established graphite UI theme; typography is unchanged.
