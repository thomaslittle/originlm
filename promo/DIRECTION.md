# Direction — OriginLM promo

## Read and assumed

- Brief is shaped: audience, one belief, format, arc and end card are given. No open question would change the story, so this proceeds without a gate.
- Assumed: "silent-viewable" means no voice track is required; I am adding a quiet local score and foley only if the local audio models are available. All meaning is in type and demonstrated state, so the film works muted.
- Assumed: the film is a product film, not a feature tour. One loop is followed: the glue pile → one inventory → one granted stream → the safety boundary → the name.
- The end card omits the npm/install line on purpose (see STORYBOARD claims map): the repo's distribution status says package identities are provisional and source packages remain private/unpublishable, so `npm install originlm` is not safe to claim.

## Look

- Brand only: graphite `#231f20` / dark background `#1e1a1b`, paper `#faf9f5`, amber `#eba31a`, raised `#2e2829`, border `#3b3334`, muted `#b0a8a1`. No palette invented.
- Face: Red Hat Display Variable, copied from `brand/fonts/`. Code fragments use a system monospace stack; that is a functional register, not a brand face.
- The real supplied SVGs are used for the mark and wordmark. Nothing is redrawn.
- One visual system: hairline grid, hard-edged cards, amber only where the eye should go (the core, the grant, the rule under the end card). No bloom stacks, no glass, no gradient type.

## Motion

- A single camera push runs the whole film (slow scale + drift, never stopping at a cut), with per-scene parallax layers at different rates.
- State changes are demonstrated, not listed: strands retract, rows resolve, a grant flips from requested to active, tokens stream.
- No still longer than ~2.5 s; the safety beat is four cuts on a moving rail.

## Exceptions noted for the floor

- The end card holds the wordmark for the last ~2.5 s while the camera and the amber rule still move; the stillness is the point (the name is the last thing to read).
- No voice means `raea check` has no word cues to score; loudness is still mastered to -14 LUFS if audio is present.
