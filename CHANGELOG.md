# Changelog

## Unreleased

- fix(desktop): collapse duplicate passive-discovery installs to one account per provider (distinct account ids are preserved), keep a stable local-token row for Claude/Codex/Gemini/Grok/Kiro even when a scan is empty, replace "Not reported" with explicit no-quota/local-total states, use green/amber/red availability meters, use the Claude burst and OpenAI marks, replace the duplicated Overview allowance cards with one provider list that shows every account with its meter or explicit no-quota/local-total state, keep quota evidence attached to the account the list keeps when a duplicate is folded away, keep the last allowance windows stale when a metadata refresh omits usage, persist and reload desktop metadata in a desktop-owned cache so last-known allowances appear immediately after restart, give Claude Code a realistic usage-control timeout and report a failed usage read instead of claiming no quota window, show every window in the provider row instead of hiding the third, and stop serializing startup metadata probes on the broker worker. Measured Windows startup to first window: 1.5s.
- fix(usage): show recorded local session-token totals on the Usage page when providers have no quota window, and let the desktop private runtime read Cursor's dashboard allowance by default. Gemini/Grok tokens now report even when no quota pool exists; Cursor reports its included-usage window.
- fix(antigravity): discover T3's managed ACP runtime and per-account `antigravity-acp` profiles, exclude desktop IDE launchers, supply the packaged auth blocker and file-backed ACP environment, allow the managed runtime's cold start, and parse its legacy model list. Windows live: two profiles authenticated with 13 models and no GUI launch.
- fix(opencode): exclude the OpenCode Desktop GUI executable from CLI discovery on Windows, and discover the npm or desktop-bundled CLI instead. This stops version probes from opening the desktop window and lets the native service probe reach the real CLI.
- fix(opencode): treat a saved OpenCode Console OAuth connection as native-reported authentication when no workspace limits are exposed, fixing Console logins that previously appeared as "Not checked" while `/connect` API-key logins worked.
- feat(usage): add `usage.history` and `costs.read.historical` plus a desktop Costs page section. History now covers Gemini CLI (`~/.gemini/tmp` JSON/JSONL), Grok (`~/.grok/sessions` `updates.jsonl` `turn_completed`), and Kiro (`~/.kiro/sessions/cli` recorded turn counts) in addition to Claude Code and Codex. Codex app-server and rollout token shapes are both accepted; cache writes stay separate from fresh input.
- feat(models): serve on-disk Ollama and LM Studio inventories through `models.local`, honor an LM Studio `modelDirectory` from `LMStudio/config.json`, and show them on the desktop Models page.
- feat(detection): add `detection.status` with per-provider found/configuration-only/not-found states, diagnostics, executable presence, and paths checked; render it on the desktop Diagnostics page. `scan --probe-versions` records explicit `--version` output for real-install evidence.
- feat(ci): add a server-off Ollama real-install job that pulls `smollm2:135m` and asserts `originlm models` lists it, and probe version output in the existing detection matrix.
- chore(upstream): pin CodeNotch `6522e9f` (`1.24.0`, MIT) as a session-layout/token-accounting cross-check; no source is copied.
- feat(detection): search per-OS fallback executable directories in addition to `PATH` (Homebrew, `/usr/local/bin`, `/snap/bin`, flatpak, Nix, npm prefixes, nvm/fnm/mise/asdf/volta shims, WinGet, scoop, Chocolatey, per-user Programs). A GUI launch with a minimal `PATH` no longer hides an installed client, and `*_EXECUTABLE_FROM_FALLBACK_LOCATION` records that a fallback supplied the hit.
- fix(detection): resolve Unix executable links before grouping installations, so a command reached through both `PATH` and its real install directory is one installation instead of two (for example `/usr/local/bin/opencode` -> `~/.opencode/bin/opencode`).
- feat(models): add `originlm models --json [--home ABSOLUTE_DIRECTORY]` for on-disk Ollama manifests and LM Studio GGUF files. It reports native ids, names, byte sizes and a coarse format, explains missing or malformed roots, and never guesses quantization, context or text capability.
- feat(usage): add `originlm usage --json [--home ABSOLUTE_DIRECTORY]`, a bounded read-only total for Claude Code `projects/`/`transcripts/` JSONL and Codex `sessions/`/`archived_sessions/` JSONL. Claude streaming duplicates merge by message key with split-aware cache fields; Codex thread totals become per-turn deltas, resumed copies dedupe by session/timestamp/total, mixed-model turns stay separate, cache reads/writes are normalized out of fresh input, and malformed or oversized input is reported. Prompts, tool output and credentials are never read or serialized.
- feat(kiro): detect `kiro-cli` and `~/.kiro`, and probe `--version`, `whoami --format json`, and the account model catalog from `chat --list-models --format json`. A signed-out `whoami` never requests models, which would start Kiro's browser login; `KIRO_API_KEY` is passed through but never serialized. Kiro execution, plan, billing, and quota stay unsupported or unknown.
- fix(usage): emit Claude `cache_read_tokens`, `cache_creation_tokens`, and `reasoning_tokens` separately, and turn Codex thread-wide `tokenUsage.total` counters into this turn's delta with `last` as the reset fallback. The old thread-wide `session_tokens` fallback remains for older app-servers.
- feat(cli): `originlm scan --json --include-locations` adds private executable and profile paths for local debugging and real-install CI; the default snapshot still omits host paths.
- chore(upstream): pin Tokscale `b26c433d` (`v4.21.0`) and T3 Code `8b44f42b` (nightly `v0.1.8-nightly.20261104.4165`, stable `v0.1.7`); parity and offline snapshot checks pass.
- build(ci): add `macos-15` (arm64) to the verification matrix and a `Detection real install` workflow that installs npm CLIs and Kiro, then scans with both the inherited PATH and a GUI-like bare PATH.
- fix(opencode): find the OpenCode 2 background service on Windows when `HOME` is unset (hosts started from Explorer, PowerShell or a service), by falling back to `USERPROFILE` as OpenCode does. Probes previously failed with `ProviderUnavailable` ("Client metadata is unavailable") and listed no OpenCode models unless the host ran under Git Bash.
- fix(opencode): resolve the npm shim of OpenCode 2.x (`@opencode/cli`) as well as 1.x (`opencode-ai`), so an npm-installed OpenCode 2 on Windows lists its models instead of reporting `RuntimeMissing`.
- build(desktop): move `originlm-desktop` from `gpui-kit` 0.8.1 (`gpui-fast` 0.1.12, `gpui-pre` 0.3.10) to `gpui-kit` 0.9.0 with the `gpui-fast` feature (`gpui-fast` 0.1.13, `gpui-pre` 0.3.11). The palette is still applied by assigning fields on the theme returned from `Theme::update`.
- build(sqlite): move `originlm-adapters` and `originlm-store` from `rusqlite` 0.32.1 to 0.37.0 (`libsqlite3-sys` 0.35, bundled SQLite stays on with `limits`). Hosts that already depend on `rusqlite` 0.37 can now link the OriginLM crates; two `rusqlite` majors cannot coexist in one binary because `libsqlite3-sys` declares `links = "sqlite3"`.
- fix(opencode): map an exact OpenCode Go Global-region refusal to the shared `PROVIDER_REGION_RESTRICTED` error code with fixed safe guidance. Neither the provider's privacy setting nor account/billing state is changed; other failures keep their existing classification.
- feat(auth): add `originlm auth antigravity`, which starts the installed ACP server, captures the Google authorization URL through a host browser helper, and waits for the callback. Metadata probes no longer start OAuth implicitly.
- feat(antigravity): add the managed ACP server installer (`originlm install antigravity`), discover the installed `agy_acp_server.par`/harness, and probe discovered ACP clients without a hand-authored profile file. Gemini CLI discovery now includes T3 Code-managed installs. Auth flows and reset credits are the next engine slice.
- build(desktop): the GPUI control center now consumes the published `originlm-control`, `originlm-platform` and `originlm-contracts` crates at `=0.1.0-alpha.22` instead of path crates, and inherits the workspace version.
- release(alpha.22): add the host-owned `--allow-identity` opt-in so an app-managed helper can reveal the provider-reported signed-in account label (email); without it the projection still withholds identity. The 14-crate closure is published at `0.1.0-alpha.22`; npm and PyPI remain at `0.1.0-alpha.20`.
- release(alpha.21): wire the OpenCode 2 text execution client into the service builder, dispatch 2.x sessions to the owner's local service API, accept the service's default model variant, and surface provider failure text. The 13-crate closure, npm platform packages and PyPI wheels are published at `0.1.0-alpha.21` / `0.1.0a21`.
